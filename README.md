# will·B·aby

A mobile-first Hebrew pregnancy-tracking PWA: a daily tip or fact, a weekly summary, journal, belly photos, tests and appointments, and a few fun tools along the way. All data stays on the device.

> Status: planning complete, development not started yet.

## Documents
- [`CLAUDE.md`](CLAUDE.md) — decisions, stack and working rules (project source of truth)
- [`docs/plan.md`](docs/plan.md) — development phases and progress tracker
- [`docs/architecture.md`](docs/architecture.md) — screens, pregnancy logic, data model, folder structure
- [`docs/content.md`](docs/content.md) — content structure and writing rules
- [`docs/design.md`](docs/design.md) — branding, colors, typography

## Stack
Next.js (static export) · TypeScript · Tailwind CSS · Dexie (IndexedDB) · PWA (service worker) · Vercel

## Disclaimer
willBaby provides general information only and is not a substitute for medical advice.
